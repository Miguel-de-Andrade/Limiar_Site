# Limiar Site

O **Limiar Site** é um projeto de desenvolvimento web desenvolvido com **HTML** e **CSS**, aplicando conceitos fundamentais de front-end.

O site também foi utilizado como base para a criação de uma **empresa fictícia**, desenvolvida como parte das atividades da disciplina **Programação Web I**, do curso de **Desenvolvimento de Sistemas da Etec da Zona Leste**. A disciplina foi ministrada pelos professores **Ralf Jerônimo** e **Gilmar Freire**, proporcionando a aplicação prática dos conhecimentos adquiridos em sala de aula por meio de um projeto completo.

Este repositório representa a evolução dos conhecimentos adquiridos durante os estudos de desenvolvimento web, unindo criatividade, funcionalidade e boas práticas de programação em um projeto desenvolvido para fins acadêmicos.

**Projeto desenvolvido por Miguel de Andrade e Levi Tavares.**
